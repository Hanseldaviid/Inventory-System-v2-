
# Object-Oriented Inventory System (v2) 📦

A robust Python application built using **Object-Oriented Programming (OOP)** principles to manage products and store inventory efficiently.

## Features
- **Composition & Encapsulation:** Clear separation between `Product` and `Inventory` classes with protected attributes and `@property` getters.
- **Data Management:** Add products, count totals, list inventory details, and search items with validation handling.
- **Clean Architecture:** Designed following modular software engineering best practices.

## Technologies
- Python 3.x
